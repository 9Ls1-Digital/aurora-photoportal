# ADR-033 – Dashboard routing and watermark recovery

- Correct plugin asset URL constant usage for watermark preview.
- Platform owner controls the shared watermark test image from Aurora Admin > Branding.
- Photographer settings retain profile/branding/email settings and add watermark controls without replacing them.
- Delivery dashboard links open aggregate delivery overview; unpaid links apply an unpaid filter.
- Resource dashboard cards route to category filters.
