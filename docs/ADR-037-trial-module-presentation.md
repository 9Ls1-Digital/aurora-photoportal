# ADR-037 — Trial module presentation and photographer subscription overview

## Status
Accepted — 2026-09-03

## Decision
Standard Trial enables every production-ready Fotoportal add-on: Premium Proof / PDF, Kundeportal, Bildevalg and Digital levering. Nettbutikk and Customer App / PWA remain disabled until production-ready.

Photographers receive a read-only Abonnement og moduler overview under Workspace settings. Aurora Admin remains the source of truth for entitlement changes.

Customer-facing labels are Bildevalg (Favoritter, kommentarer og redigeringsønsker) and Digital levering (Sikker levering av ferdige høyoppløselige bilder). Internal module keys remain unchanged for backwards compatibility.
