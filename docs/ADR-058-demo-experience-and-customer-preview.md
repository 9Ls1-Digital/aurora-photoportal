# ADR-058 – Demo experience and customer preview

**Version:** 0.7.1-dev.46-project-flow-ux  
**Date:** 2026-09-11

## Decision
Aurora Demo Content Pack is treated as a complete Trial experience rather than a gallery-only seed. Distribution is managed through a scalable account table. Active demo contracts/documents are materialized into the account-scoped demo project as test records while also remaining available as reusable resources. The seeded demo customer receives a dedicated test login, exposed only to the photographer/admin on the test customer card, with guidance to use a separate browser or incognito window.

The global gallery index is a gallery management surface and therefore does not render project workflow steps. It renders a compact watermark preview using the photographer's current watermark settings.

## Safety / tenancy
All generated project, gallery, contract and document records remain test content (`is_test=1`) and are tied to the Trial account through the existing client/project tenancy chain. Demo customer credentials are for test content only and are regenerated by Demo Content Pack provisioning.
