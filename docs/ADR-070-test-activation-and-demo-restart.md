# ADR-070 – Test activation and authoritative Demo Journey restart

Date: 2026-09-14  
Status: Accepted

## Context
The permanent Test-fotograf introduced in dev.55 reused a completed onboarding state so administrators could jump directly into Demo Journey. That made invitation/password activation skip the six-step photographer onboarding. Demo Content provisioning also marked the Demo-kit as downloaded, and Demo Journey restart preserved that marker. As a result, step 1 could appear completed without an actual download and restart could open directly on step 2.

## Decision
- Sending or resending an invitation to an account marked `is_test_account=1` first resets that account to a clean onboarding state while preserving its permanent photographer identity and fixture profile.
- Password activation has a second safeguard for Test-fotograf accounts so invitation links generated by older builds still enter onboarding step 1.
- Demo Content Pack provisioning is no longer treated as a Demo-kit download.
- Demo Journey owns its progress state; it no longer imports `kit_downloaded_at` from Demo Content Pack state.
- `Start på nytt` is a true restart: generated guided-demo content is removed, kit download markers are cleared and the Journey reopens on step 1.
- Test Harness cleanup now removes the correct `aurora_fotoportal_demo_pack_account_{id}` option, while also removing the previous typo key for compatibility.
- Demo Journey is available to both Trial accounts and the permanent Test-fotograf.
- The `Lær Fotoportal` Demo Journey card is placed first on the photographer Dashboard.
- Progress boxes use a more compact responsive grid so the full ten-step visible training sequence is easier to scan.

## Consequences
The permanent Test-fotograf can now be used for a complete regression path: invitation → password → six-step onboarding → Dashboard → Demo-kit download → guided Demo Journey, without recreating the account. Existing stale Demo-kit progress can be cleared by `Start på nytt`.
