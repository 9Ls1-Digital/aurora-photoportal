# ADR-013 — Native Delivery in Photographer Workspace

Status: Accepted for development

dev.19 moves Delivery into the Photographer Workspace and completes the native
five-step project workflow. Delivery currently summarizes readiness from the
existing project, contract and gallery data model and allows project status to
be maintained without leaving Aurora.

Customer Portal, approval automation and final HQ delivery remain future
modules and are not invented as part of this migration.
